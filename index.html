Student Task Manager — CI/CD Pipeline

A task manager web app with a fully automated delivery pipeline. Every push to GitHub triggers Jenkins, which builds a Docker image, pushes it to Docker Hub, and lets Kubernetes run it as two pods behind a Service on AWS.
